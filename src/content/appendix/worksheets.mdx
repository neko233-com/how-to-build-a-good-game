这一章把书里的方法做成可以直接填的表。用法很简单：**复制一张表，按表头填，填不出来就是你要去查的地方。**

<Callout type="note" title="怎么用这些表">
  不要一次填完所有表。按项目所处阶段选一张——立项前填第 1、2 张，做原型时填第 3 张，准备上线时填第
  4、5 张，项目结束时填第 6 张。第 7 张是总表，可以整份打印。
</Callout>

## 工作表 1：能力地板三把尺

来自第 05 章。三把尺子分开填，不要混成一个笼统的印象。

| 来源     | 填什么                                                          | 你的读数 |
| -------- | --------------------------------------------------------------- | -------- |
| 竞品拆解 | 2–3 个**直接**竞品，逐项对照（画质 / 手感 / 内容量 / 更新节奏） |          |
| 竞品拆解 | 这些竞品里，玩家最常夸的一点是什么                              |          |
| 竞品拆解 | 玩家最常骂的一点是什么（这往往是没人做到的地方）                |          |
| 用户预期 | 问 3 个玩过本品类的人：你最不能忍什么                           |          |
| 用户预期 | 这些「不能忍」里，有几条是你现在的方案也会犯的                  |          |
| 渠道准入 | 目标平台的推荐位 / 买量准入要求是什么                           |          |
| 渠道准入 | 这些要求在最近一年变过吗                                        |          |
| **结论** | 我的地板估计：明显低于 / 略高于 / 换了一把尺子                  |          |

## 工作表 2：客群与流量四问

来自第 06 章。任何一问答「所有人」，就是定位还没成立。

| 问题       | 填什么                                                     | 常见错误                      |
| ---------- | ---------------------------------------------------------- | ----------------------------- |
| 谁在玩     | 年龄段 / 性别倾向 / 城市层级 / 设备 / 使用场景             | 「男女老少都能玩」            |
| 从哪来     | 应用商店 / 平台推荐 / 买量 / 社交裂变 / 搜索 / 直播        | 只写「买量」，没写买哪里的量  |
| 为什么留下 | 内容消耗型（还有东西没看）还是数值成长型（今天还有事没做） | 两种都写，等于没说清楚        |
| 怎么付钱   | 内购（大 R 集中）/ 广告（底盘均匀）/ 买断                  | 只写「内购 + 广告」，没写比重 |

## 工作表 3：核心循环缺口诊断

来自第 03 章。四环逐环检查，缺一环就是缺口。

| 环       | 检查问题                                                 | 你的答案 | 是否成立 |
| -------- | -------------------------------------------------------- | -------- | -------- |
| 行动     | 玩家此刻做的选择有意义吗？列出三个选项，它们代价相同吗？ |          |          |
| 反馈     | 世界多久回应一次？玩家能看出「是我的行动造成的」吗？     |          |          |
| 奖励     | 回报是确定的、可归因的吗？还是随机到像噪音？             |          |          |
| 成长     | 变强之后，下一轮行动出现了新选择吗？                     |          |          |
| **取舍** | 玩家在什么时候承担什么风险、换取什么回报？               |          |          |

## 工作表 4：验证漏斗设计

来自第 16 章。**通过标准和止损后果必须在动作开始前填好**，否则这张表没有意义。

| 阶段       | 要验证的假设             | 怎么做（最小动作） | 通过标准（事前定） | 不通过就做什么（具体动作） |
| ---------- | ------------------------ | ------------------ | ------------------ | -------------------------- |
| 素材测试   | 题材与包装有吸引力吗     |                    |                    |                            |
| 试玩广告   | 核心操作能抓住人吗       |                    |                    |                            |
| 灰盒原型   | 循环闭合、重复玩还成立吗 |                    |                    |                            |
| 小规模上线 | 留存与付费成立吗         |                    |                    |                            |

<Callout type="tip" title="填写检查">
  「不通过就做什么」这一栏如果写的是「继续观察」或「再优化一下」，说明你还没想清楚——它必须是一个**可以执行的放弃动作**，比如「砍掉这个题材，换下一个」。
</Callout>

## 工作表 5：数值论证五问自检

来自第 15 章。拿最近一次向老板 / 投资人 / 团队做的分析，逐条过。

| 问题                                          | 是 / 否 | 说明 |
| --------------------------------------------- | ------- | ---- |
| 1. 事前有门槛吗？（还是事后画的线）           |         |      |
| 2. 它有预测义务吗？（事先说过可能落空的话吗） |         |      |
| 3. 换一个同样合理的参数，结论会反过来吗？     |         |      |
| 4. 这个解释是不是只有在成功后才知道？         |         |      |
| 5. 同一套数值能同样好地解释一个失败案例吗？   |         |      |

五问里有一个答不上来，这个论证就不该被当成依据。

| ---------------------- | ---------------- |

## 工作表 7：从 0 到 1 总清单

来自第 18 章。整份打印，逐项打勾。

| 序号 | 阶段       | 动作                       | 通过标准                     | 止损条件                 | 状态 |
| ---- | ---------- | -------------------------- | ---------------------------- | ------------------------ | ---- |
| 0    | 定位       | 一句话说清「给谁解决什么」 | 说给目标用户听，对方能复述   | 换三个人都听不懂         | ☐    |
| 1    | 题材验证   | 素材测试                   | 点击率高于自家历史基线       | 两轮素材都低于基线       | ☐    |
| 2    | 玩法验证   | 试玩广告 / 纸面原型        | 陌生人在被打断状态下愿意玩完 | 核心操作 30 秒抓不住人   | ☐    |
| 3    | 循环验证   | 灰盒原型自测               | 自己反复玩两周后循环仍闭合   | 说不出缺口在哪一环       | ☐    |

| 5    | 客群定位   | 四问（工作表 2）           | 四问都能具体到人群与入口     | 任何一问答「所有人」     | ☐    |
