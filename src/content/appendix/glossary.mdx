本书尽量用中文行业里的通行说法，同时对容易含混的词给出定义。定义按书中第一次出现的语境写，方便对照。

## 判断与竞争

| 术语                   | 定义                                                                                              |
| ---------------------- | ------------------------------------------------------------------------------------------------- |
| **能力地板**           | 同一时期、同一品类里，同行普遍都能做到的水准。低于它等于没有产品（第 05 章）                      |
| **及格线**             | 与「能力地板」同义，但在讨论「分数」时使用：它是相对的，会随行业水位上移（第 04 章）              |
| **60 分等于 0 分**     | 当同行都能做到 60 分时，60 分不再带来回报，只是入场券（第 04 章）                                 |
| **更好一点 vs 不一样** | 前者在同一把尺子上多拿几分，后者换了比较的基准（第 05 章）                                        |
| **滩头市场**           | 一个足够小、足够具体、可以彻底赢下的细分市场，用作向外扩张的起点（第 08 章，源自 Geoffrey Moore） |

## 设计与机制

| 术语         | 定义                                                                               |
| ------------ | ---------------------------------------------------------------------------------- |
| **核心循环** | 玩家在短时间内反复经历的最小单元：行动 → 反馈 → 奖励 → 成长（第 03 章）            |
| **取舍**     | 玩家在同一节点上不同选项的代价不同；没有取舍的操作不是玩法（第 03 章）             |
| **心流**     | 明确目标、即时反馈、难度匹配三者满足后出现的状态，不能直接作为目标追求（第 03 章） |
| **灰盒原型** | 用占位美术与最小实现验证结构的原型，刻意不做打磨（第 16 章）                       |
| **完成度**   | 画质、手感、内容量等可投入换取的维度；与「好玩」是两个独立维度（第 02 章）         |

## 客群与流量

| 术语               | 定义                                                                         |
| ------------------ | ---------------------------------------------------------------------------- |
| **客群结构**       | 谁在玩：年龄、性别倾向、城市层级、设备与使用场景的组合（第 06 章）           |
| **流量结构**       | 用户从哪来：应用商店、平台推荐、买量、社交裂变、搜索等入口的组合（第 06 章） |
| **内容消耗型留存** | 玩家留下是因为「还有东西没看到」（第 06 章）                                 |
| **数值成长型留存** | 玩家留下是因为「今天还有事没做完」（第 06 章）                               |
| **自然量**         | 不花买量费用获得的用户；讨论它时应看作比率而非绝对数量（第 06 章）           |

## 留存与商业化

| 术语                  | 定义                                                                                                            |
| --------------------- | --------------------------------------------------------------------------------------------------------------- |
| **D1 / D7 / D30**     | 新增用户在次日 / 第 7 日 / 第 30 日仍回访的比例。D1 反映第一印象，D7 反映核心循环，D30 反映长期价值（第 17 章） |
| **DAU / MAU**         | 日活跃用户数 / 月活跃用户数（第 17 章）                                                                         |
| **LTV**               | 单个用户在整个生命周期内贡献的收入（第 07 章）                                                                  |
| **CAC**               | 获取一个用户所付出的成本（第 07 章）                                                                            |
| **CPI**               | 单次安装成本，买量中最基础的计价单位（第 07 章）                                                                |
| **回收点 / 回收周期** | 累计收入追平获客成本的那一天 / 所需时间。它比利润率更早决定生死（第 07 章）                                     |
| **ARPU / ARPPU**      | 每用户平均收入 / 每付费用户平均收入（第 07 章）                                                                 |
| **付费深度分布**      | 付过费的人分别落在哪些档位；只看付费率会被头部拉高的平均数骗过（第 17 章）                                      |
| **IAA / IAAP**        | 广告变现 / 广告与内购混合变现。微信平台以「内购流水占比是否达到 30%」划分（第 06 章）                           |

## 验证与数据

| 术语                    | 定义                                                                                               |
| ----------------------- | -------------------------------------------------------------------------------------------------- |
| **验证漏斗**            | 按成本从低到高排列的四级验证：素材测试、试玩广告、灰盒原型、小规模上线（第 16 章）                 |
| **素材测试**            | 用广告素材测量题材与包装的吸引力；能否决，不能批准（第 16 章）                                     |
| **试玩广告**            | 让用户在广告里直接玩一小段，用以验证核心操作的抓人力（第 16 章）                                   |
| **事后门槛**            | 看到数据之后才定下的通过标准；等于没有标准（第 16 章）                                             |
| **示意数字**            | 用于说明结构关系的模型数值，不是实测统计。书中这类数字都会标注（全书通用）                         |
| **一手来源**            | 官方发布、本人演讲或访谈原话、同行评审论文（附录 A）                                               |
| **可解释性的对称性**    | 成功与失败都能被同一套数值解释通，说明这套数值没有区分力（第 15 章）                               |
| **Goodhart 定律**       | 一项统计规律一旦被用于控制目的，它就会失效（第 17 章）                                             |
| **Campbell 定律**       | 量化指标一旦用于决策，就会被腐蚀并扭曲它本欲监测的过程（第 17 章）                                 |
| **指标迷恋**            | 用标准化测量取代基于经验的判断（第 15 章，源自 Jerry Muller）                                      |
| **幸存者偏差**          | 只观察存活样本，从而系统性高估某些做法的成功率（第 17 章）                                         |
| **结果指标 / 过程指标** | 前者描述发生了什么（如留存率），后者描述正在往哪走（如引导完成率）；前者不能被直接行动（第 17 章） |

## 设计与工艺

| 术语                 | 定义                                                                         |
| -------------------- | ---------------------------------------------------------------------------- |
| **主玩法**           | 支撑核心循环的那一套操作与规则，是产品决策的产物（第 09 章）                 |
| **副玩法**           | 围绕主玩法搭的辅助系统，承担留存延长、付费分层与素材多样性（第 10 章）       |
| **选题**             | 决定卖给谁、卖什么题材，是市场决策；它先于玩法（第 09 章）                   |
| **可演示性**         | 题材或玩法能否在 15 秒素材里被讲清，直接影响获客效率（第 09 章）             |
| **手感**             | 从输入到动作之间的响应质量，由重力、初速、加速度、缓冲等参数构成（第 12 章） |
| **输入缓冲**         | 落地前提前按跳仍然生效的时间窗口，用来宽容玩家时机误差（第 12 章）           |
| **土狼时间**         | 离开平台边缘后仍可起跳的宽限时间（第 12 章）                                 |
| **顿帧（hit stop）** | 命中瞬间短暂停顿画面，用来制造打击的重量感（第 12、13 章）                   |
| **反馈感**           | 从动作到结果之间的反馈质量，分视觉、听觉、触觉三类（第 13 章）               |
| **飘字**             | 把数值结果以浮动文字呈现，让结果可被读到（第 13 章）                         |
| **反馈分级**         | 按事件重要性配置反馈强度；普通克制、关键拉满（第 13 章）                     |
| **2.5D**             | 等距或固定视角的伪三维呈现：有纵深感，但不处理复杂镜头（第 14 章）           |
