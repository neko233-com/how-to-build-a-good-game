本书尽量用中文行业里的通行说法，同时对容易含混的词给出定义。定义会随正文写作继续补充。

## 留存与活跃

| 术语          | 定义                                                                                                          |
| ------------- | ------------------------------------------------------------------------------------------------------------- |
| D1 / D7 / D30 | 新增用户在次日 / 第 7 日 / 第 30 日仍然回访的比例。D1 反映第一印象，D7 反映核心循环是否成立，D30 反映长期价值 |
| 次留          | 即 D1，中文行业里更常用的说法                                                                                 |
| DAU / MAU     | 日活跃用户数 / 月活跃用户数。两者的比值（DAU/MAU）常被用来粗略衡量使用黏性                                    |

## 商业化

| 术语                             | 定义                                                         |
| -------------------------------- | ------------------------------------------------------------ |
| LTV（Life Time Value）           | 单个用户在整个生命周期内贡献的收入                           |
| CAC（Customer Acquisition Cost） | 获取一个用户所付出的成本                                     |
| CPI（Cost Per Install）          | 单次安装成本，买量中最基础的计价单位                         |
| 回收周期                         | 累计收入追平获客成本所需的时间。它比利润率更早决定项目的生死 |
| ARPU / ARPPU                     | 每用户平均收入 / 每付费用户平均收入                          |
| 付费漏斗                         | 从「进入游戏」到「完成付费」的逐级转化链路                   |

## 方法论

| 术语       | 定义                                                                               |
| ---------- | ---------------------------------------------------------------------------------- |
| 素材测试   | 用若干套广告素材投放，测量点击与转化，以此推测题材与包装的吸引力                   |
| 试玩广告   | 让用户在广告里直接玩一小段可交互内容，用以验证玩法本身是否有吸引力                 |
| 灰盒原型   | 用占位美术与最小实现验证玩法结构的原型，刻意不做打磨，以免把「好看」误当成「好玩」 |
| 能力地板   | 同一时期、同一品类里，同行普遍都能做到的水准。低于它等于没有产品                   |
| 幸存者偏差 | 只观察存活下来的样本，从而系统性高估某些做法的成功率                               |
