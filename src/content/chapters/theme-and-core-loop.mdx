先讲一个常见的失败顺序。

一个团队花三个月做出了一个非常扎实的核心玩法：操作顺滑、判定精准、连招有深度。做完之后他们开始想：这个游戏卖给谁？

答案是「喜欢动作游戏的人」。再往下问：这个品类里已经有多少同类？它们做到什么水平？我们的题材在买量素材里好不好讲？——三个问题，团队一个都答不上来。

这就是顺序反了。**玩法是产品决策，选题是市场决策**。先做玩法再找市场，等于先造零件再找有没有人需要这辆车。

<Callout type="warning" title="本章的前提">
  这本书把「必须有市场、必须能成功」当作最基本的要求。所以本章讨论的不是「怎么做出一个有创意的玩法」，而是「怎么在一个已经被验证的需求里，选出一个能被做出来、也能被卖出去的玩法」。创意不是被否定的，它只是排在市场之后。
</Callout>

## 选题是市场决策

选题回答的是三个问题，每一个都只有市场能回答：

<CompareTable caption="选题的四个判据（都可以去查，不需要拍脑袋）">

| 判据             | 要问的问题                               | 怎么得到答案                         |
| ---------------- | ---------------------------------------- | ------------------------------------ |
| 人群规模与接受度 | 这个题材覆盖多少人？他们接受度如何？     | 看同题材产品的量级与评论；看平台榜单 |
| 竞争密度         | 这个题材最近一年出了多少同类？头部多强？ | 平台搜索 + 新游榜 + 买量素材库       |
| 可演示性         | 这个题材能不能在 15 秒素材里讲清？       | 拿三张图试着拼一个广告               |
| 能力匹配         | 我们能不能做出这个题材的下限？           | 对照第 05 章的能力地板三把尺         |

</CompareTable>

四个判据里，最容易被跳过的是**可演示性**。它决定的是获客效率：一个「一句话就能讲清」的题材，素材测试的通过率天然更高；一个需要玩三小时才能体会妙的题材，在信息流里几乎无法被理解——它可能是个好游戏，但它不适合这个渠道。

## 主玩法是产品决策

主玩法回答的是另一个问题：**用一个循环，能不能让人愿意再来一次。**

第 03 章给过循环的四环。这里补四个判据，用来判断一个玩法能不能当「主」：

<CompareTable caption="主玩法的四个判据">

| 判据           | 含义                                       | 不成立会怎样           |
| -------------- | ------------------------------------------ | ---------------------- |
| 一个循环能成立 | 30 秒内完成一次「行动→反馈→奖励→成长」     | 玩家不知道自己在干什么 |
| 可被看到       | 玩法在画面上是「可见的」：动作、特效、结果 | 素材无法体现卖点       |
| 可被广告演示   | 15 秒内能让人看懂并想试                    | 获客成本被推高         |
| 可被扩展       | 能长出新的关卡、角色、模式                 | 内容很快见底           |

</CompareTable>

第三条常被忽略，但它直接连着商业模型。一个「需要长时间沉浸才能体会」的主玩法，在买量渠道里几乎必然吃亏——不是玩法不好，是它和渠道的表达方式不匹配。

## 选题与主玩法的匹配

选题和主玩法不是两个独立的选择，它们必须互相支撑。

<CompareTable caption="匹配矩阵：四种组合的典型结果（示意）">

| 组合                  | 典型表现                                       | 风险                           |
| --------------------- | ---------------------------------------------- | ------------------------------ |
| 热门题材 + 成熟主玩法 | 获客容易，但同质化严重，拼的是执行力与投放效率 | 地板极高，容易做成分母         |
| 热门题材 + 新主玩法   | 最有爆发潜力的组合，素材讲得清、玩法又有新鲜感 | 新玩法的验证成本高，容易做不成 |
| 冷门题材 + 成熟主玩法 | 获客便宜，但天花板低                           | 规模上不去，团队养不活         |
| 冷门题材 + 新主玩法   | 通常是自嗨型项目的高发区                       | 既没人看得懂，也没人愿意试     |

</CompareTable>

矩阵里最危险的不是右下角（大家一看就知道难），而是左上角：**热门题材 + 成熟主玩法**。它看起来最安全——题材有人看、玩法被验证过——但正因为如此，全行业都在做，地板被推得最高。

## 反方观点：先有玩法再找题材，不也有成功的吗

有。而且这类故事特别容易被传播，因为它符合「创意胜利」的叙事。

但要注意两件事：第一，**幸存者偏差**（第 17 章）：我们看到的是「先做玩法然后找到了市场」的成功者，看不到大量「先做玩法然后找不到市场」的项目。第二，那些成功案例里的「玩法」，事后看往往是**玩法与题材一体**的——它们不是先有玩法再配题材，而是一开始就长在一起。

真正可行的顺序是：**用市场选定一个范围，在范围内找一个能成立的玩法**。市场划定边界，玩法在边界内创新。这既不是纯市场导向（那会做出没有灵魂的换皮），也不是纯创意导向（那会做出没人要的好游戏）。

## 这一章可以带走什么

- 选题是市场决策，主玩法是产品决策；顺序反了，就会做出没人要的好游戏。
- 选题查四件事：人群规模、竞争密度、可演示性、能力匹配。最容易被跳过的是可演示性。
- 主玩法查四件事：一个循环能成立、可被看到、可被广告演示、可被扩展。
- 警惕「热门题材 + 成熟主玩法」这个看起来最安全、实际地板最高的组合。
- 正确的顺序是：用市场划范围，在范围内找玩法。
