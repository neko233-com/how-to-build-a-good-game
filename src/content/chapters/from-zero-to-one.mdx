前面十一章各自回答了一个问题。这一章把它们收拢成一份可以照着做的清单——**从 0 到 1，每一步该做什么、怎么知道该停。**

## 清单的结构

整本书的论证可以压缩成一条主线：**先确认值得做（存在性），再确认做得好（循环），再确认活得起（市场与现金流），全程用最便宜的方式买信息（验证）**。清单就按这条主线排。

<CompareTable caption="从 0 到 1 的检查清单（每行：动作 → 通过标准 → 止损条件）">

| 阶段         | 最小可验证动作             | 通过标准（事前定）           | 止损条件（事前定）       |
| ------------ | -------------------------- | ---------------------------- | ------------------------ |
| 0 定位       | 一句话说清「给谁解决什么」 | 说给目标用户听，对方能复述   | 换三个人都听不懂         |
| 1 题材验证   | 素材测试（第 16 章）       | 点击率高于自家历史基线       | 两轮素材都低于基线       |
| 2 玩法验证   | 试玩广告 / 纸面原型        | 陌生人在被打断状态下愿意玩完 | 核心操作 30 秒抓不住人   |
| 3 循环验证   | 灰盒原型自测（第 03 章）   | 自己反复玩两周后循环仍闭合   | 说不出缺口在哪一环       |
| 4 地板对照   | 竞品拆解三把尺（第 05 章） | 在某个维度「不一样」且可感知 | 只能说出「我们更好一点」 |
| 5 客群定位   | 客群四问（第 06 章）       | 四问都能具体到人群与入口     | 任何一问答「所有人」     |
| 6 小规模上线 | 买量测试（第 16、17 章）   | 回收周期在现金可撑范围内     | 三道止损线任一触线       |
| 7 放大       | 逐渠道加价，逐档监控       | 边际回报仍大于边际成本       | 总量线触线即停           |

</CompareTable>

使用规则只有两条，但都必须遵守：

1. **通过标准和止损条件都必须在动作开始前写下**（第 16 章）。事后补的门槛不是门槛。
2. **顺序不能跳**。每个阶段的便宜问题没问完，不要进入下一阶段——这是整份清单唯一不可协商的部分。

## 翻译到非游戏项目

这份清单的结构是通用的，字段是游戏的。翻译的方法（第 08 章）：**保留结构，替换材料。**

<CompareTable caption="清单的跨行业翻译（示意）">

| 清单条目   | 游戏里的材料                      | 其他产品的材料               |
| ---------- | --------------------------------- | ---------------------------- |
| 题材验证   | 广告素材测试                      | 落地页 A/B 测试              |
| 玩法验证   | 试玩广告                          | 可交互 demo / 试用版         |
| 循环验证   | 灰盒原型                          | 最小可用流程走通             |
| 地板对照   | 竞品拆解三把尺                    | 同行产品基准对照             |
| 客群四问   | 谁在玩 / 从哪来 / 为何留 / 怎么付 | 同样四问，把「玩」换成「用」 |
| 小规模上线 | 买量测试                          | 冷启动渠道投放               |

</CompareTable>

结构不变的部分：**事前定标准、便宜问题先问、能否证就不能批准、结果指标翻译成过程指标再行动**。这些是原理，不随行业过期。

## 反方观点：清单会让人变笨吗

可以想见的担忧：照清单做事，会不会把判断力外包掉？

清单管的是**顺序和止损**，不管**内容**。第 0 步「给谁解决什么」答得多好、第 4 步「不一样」做得多有说服力，清单帮不上任何忙——那仍然是判断、品味和对人群的理解。清单保证的只是：你的判断被用在正确的地方，而不是用来事后解释一个本可以更早发现的问题。

换个说法：**清单不产生好游戏，它只是让坏想法死得更便宜**。而这恰恰是从 0 到 1 阶段最需要的性质。

## 这一章可以带走什么

- 主线：确认值得做 → 确认做得好 → 确认活得起，全程用最便宜的方式买信息。
- 八个阶段，每行三个字段：动作、事前定下的通过标准、事前定下的止损条件。
- 顺序不能跳；便宜的问题没问完，不进下一阶段。
- 翻译到其他行业：保留结构（事前标准、便宜先问、否证优先），替换材料。
- 清单不产生好游戏，它让坏想法死得更便宜——这就是它的全部工作。
