打开任何一个平台的畅销榜，找一款「只有一个玩法」的游戏——很难找到。

绝大多数商业产品都是**主玩法 + 若干副玩法**的结构。这不是设计上的贪心，而是三件不同的事需要三个不同的系统来承担。

## 副玩法在承担什么

副玩法不是「多加点内容」，它解决的是主玩法解决不了的问题：

<CompareTable caption="副玩法的三个功能">

| 功能       | 为什么主玩法做不到                           | 典型副玩法               |
| ---------- | -------------------------------------------- | ------------------------ |
| 延长留存   | 主玩法的新鲜感会衰减，靠它撑不过第一周       | 养成、收集、日常、赛季   |
| 付费分层   | 主玩法追求公平，而公平的系统很难承载付费深度 | 抽卡、礼包、外观、通行证 |
| 素材多样性 | 主玩法能产出的「可演示片段」数量有限         | 剧情、角色、社交、经营   |

</CompareTable>

第三条最容易被忽略。买量需要持续产出新素材，而一个纯动作游戏能剪的片段是有限的——同一套动作剪十版就重复了。副玩法提供的是**新的素材来源**，这直接决定获客能不能持续。

## 常见的五种组合

<CompareTable caption="常见玩法组合、作用与代价">

| 组合               | 作用                       | 代价                               | 适合谁                 |
| ------------------ | -------------------------- | ---------------------------------- | ---------------------- |
| 主玩法 + 养成      | 最标准的留存与付费延长     | 数值曲线一旦失控，主玩法会被架空   | 绝大多数商业化产品     |
| 主玩法 + 社交      | 提高留存下限、制造自然传播 | 冷启动期社交是负资产（没人陪你玩） | 有量级基础的产品       |
| 主玩法 + roguelike | 用随机性换取重复可玩性     | 随机要设计得「可控」，否则变成运气 | 内容生产受限的小团队   |
| 主玩法 + 经营      | 提供长期目标与情感依附     | 两套循环节奏冲突，容易两头都不深   | 休闲、模拟类           |
| 主玩法 + PvP       | 最强的留存与付费驱动之一   | 匹配、平衡、外挂三座大山           | 有运营能力的中大型团队 |

</CompareTable>

表格里最值得注意的是「代价」那一列。**每一种组合都不是免费的**：养成会架空主玩法，社交在冷启动期是负资产，roguelike 的随机需要精密控制，经营的节奏会和主玩法打架，PvP 会带来三座长期的山。

## 组合的两种错误

**第一种：把副玩法当主玩法的补丁**。主玩法不好玩，于是加养成、加剧情、加收集，希望用别的东西留住人。这几乎一定失败——因为玩家第一天来，是因为主玩法；第一天走，也是因为主玩法。副玩法只能延长，不能挽回。

**第二种：副玩法之间互不相干。**主玩法是动作，副玩法是经营，两者没有任何资源或情感上的连接。玩家的时间被切成两半，每一半都不够深。好的组合是**资源互流**的：主玩法产出的东西，是副玩法的输入；副玩法的成长，反过来改变主玩法的体验。

<Callout type="tip" title="一个判断标准">
  问自己一句：**如果去掉所有副玩法，主玩法还能不能让人玩上三天**？能，副玩法就是在放大一个已经成立的东西；不能，副玩法就是在掩盖一个还没解决的问题。
</Callout>

## 组合的节奏

主玩法与副玩法的时间占比，会随玩家生命周期变化：

- **第一天**：主玩法占绝大多数。玩家来是为了「玩」，不是来「养」。
- **第一周**：副玩法开始承担主要留存。主玩法的新鲜感衰减，成长与收集接手。
- **一个月后**：副玩法（尤其是社交与赛季）成为留下的主要理由。

这条曲线解释了一个常见错误：**在第一天就向玩家展示全部副玩法**。新手阶段堆满养成面板、任务列表、活动入口，玩家会在理解主玩法之前就被信息量劝退。

## 反方观点：加得越多，不是越杂吗

是。而且「杂」的代价很具体：**每个副玩法都会分走玩家的注意力，而注意力是有限的。**

所以组合的原则不是「越多越好」，而是**一条主线 + 一到两个支撑**。判断标准是：这个副玩法是否让主玩法变得更好？如果它只是「另一个可以玩的东西」，它就是在稀释。

反面案例的典型形态是：主玩法、经营、卡牌、塔防、社交、家园，六个系统各自独立，每个都只做了三成。玩家的体验是「什么都有，什么都不深」——这比只做一个系统更糟，因为开发成本全花了，而没有一个系统达到地板。

## 这一章可以带走什么

- 副玩法承担三件事：延长留存、付费分层、素材多样性。第三件常被忽略但决定获客能否持续。
- 五种常见组合各有代价：养成会架空主玩法、社交在冷启动期是负资产、roguelike 的随机要可控、经营的节奏会冲突、PvP 有三座大山。
- 两种错误：把副玩法当补丁；副玩法之间互不相干。
- 好组合的标准是资源互流：主玩法的产出是副玩法的输入，副玩法的成长改变主玩法的体验。
- 顺序别错：第一天让玩家理解主玩法，副玩法在之后逐步展开。
