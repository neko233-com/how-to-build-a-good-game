「手感好」是最难被量化、也最容易被说成玄学的评价。但它其实不是一个形容词，而是一组参数的结果。

这一章先把手感拆成可以调的参数，再列出市面上的几种手感流派，最后给一个能亲手调的工具。

## 手感由哪些参数构成

<CompareTable caption="影响手感的七个参数（横版跳跃为例，其它品类可类比）">

| 参数        | 它决定什么                       | 调大的后果                           | 调小的后果                         |
| ----------- | -------------------------------- | ------------------------------------ | ---------------------------------- |
| 重力        | 落得多快、动作有多「飘」或「沉」 | 滞空短、动作沉重、容错低             | 滞空长、动作轻快、容易「像在月球」 |
| 起跳初速    | 起跳的瞬间爆发力                 | 跳得高但难控制                       | 跳得稳但不够痛快                   |
| 水平加速度  | 从静止到全速要多久               | 响应快，但容易滑过头                 | 有重量感，但操作迟钝               |
| 摩擦 / 减速 | 松手后多久停下                   | 停得快，精确                         | 会有惯性滑行，容易掉下去           |
| 输入缓冲    | 落地前提前按跳是否生效           | 宽容，手指不精确也不失误             | 严格，要求精确时机                 |
| 土狼时间    | 离开平台边缘后仍可起跳的宽限     | 宽容，但会让人觉得「平台边缘变宽了」 | 严格，手感硬核                     |
| 顿帧        | 命中或受击时画面短暂停顿         | 打击感强，但节奏拖沓                 | 干脆，但缺少分量                   |

</CompareTable>

这张表最有价值的地方是**每一行都有代价**。不存在「全都调大更好」——宽容度高会让硬核玩家觉得不精确，精确度高会让移动端玩家觉得难用。手感是取舍，不是优化。

## 市面上的几种手感流派

<CompareTable caption="六种手感流派、适用场景与代价">

| 流派                 | 参数特征                   | 适合的品类         | 代价                               |
| -------------------- | -------------------------- | ------------------ | ---------------------------------- |
| 马里奥式（弹簧感）   | 高初速、中重力、宽缓冲     | 平台跳跃、休闲动作 | 精确性让位于爽快，难度设计要更小心 |
| 银河恶魔城式（精确） | 高重力、低初速、窄缓冲     | 探索、动作、硬核   | 上手门槛高，泛用户容易被劝退       |
| 魂系式（重量感）     | 低初速、高重力、长前摇     | 对抗、硬核动作     | 移动端体验差，节奏偏慢             |
| 移动端轻触           | 宽缓冲、宽土狼、强吸附     | 休闲、小游戏       | 缺乏操作深度，长期留存靠内容       |
| 格斗式（输入严格）   | 帧级判定、无缓冲、惩罚重   | 竞技、格斗         | 学习曲线陡，新人流失快             |
| 竞速式（惯性）       | 加速度低、摩擦低、转向平滑 | 竞速、飞行、滑行类 | 需要玩家理解惯性，教学成本高       |

</CompareTable>

选择流派的依据不是「哪个高级」，而是**你的玩家在什么设备上、用多少注意力玩**。一个单手在地铁上玩的游戏，不该用格斗式的输入严格性；一个面向硬核玩家的动作游戏，也不该用移动端的宽容度。

## 亲手调一遍

下面这个沙盒把上面那七个参数中的六个做成了滑块。先按默认值跳几次，再切换预设，感受落点预测、滞空时间和「宽容度」的变化。

<GameFeelPlayground />

几个值得留意的点：

- 把**重力调大、初速调小**，你会立刻觉得「沉」；反过来就是「飘」。这是流派差异最直接的来源。
- 把**输入缓冲调到 200ms**，落地前提前按跳也会生效——手感会明显变「跟手」，但这也在降低操作难度。
- 把**土狼时间调到 0**，从平台边缘跳出去就再也跳不起来，玩家会觉得「判定有问题」。
- **摩擦**决定松手后的滑行距离。滑行越长，落点越难预测。

## 反方观点：都参数化了，手感不就千篇一律了

恰恰相反。参数化不是为了让所有游戏手感一样，而是让「不一样」变成可复现、可讨论、可迭代的东西。

没有参数化时，手感调整全靠某个人的直觉，改一处坏一处，而且无法交接。参数化之后，你可以明确说「我们的重力比马里奥高 40%，缓冲比它窄一半」——这才是做出差异的前提。

真正的风险不是参数化，而是**把参数当成目标**：为了「手感好」把所有参数往爽的方向调，最后得到一个各方面都还行、但没有任何主张的手感。好的手感是**有主张的取舍**，不是每一项的最优解。

## 这一章可以带走什么

- 手感由一组具体参数构成：重力、初速、加速度、摩擦、输入缓冲、土狼时间、顿帧。
- 每个参数都有代价，手感是取舍不是优化。
- 选流派的依据是玩家在什么设备上、用多少注意力玩，不是哪个流派更高级。
- 参数化让「不一样」变得可复现、可讨论、可交接。
- 风险不是参数化，而是把参数当目标——结果是没有主张的手感。
