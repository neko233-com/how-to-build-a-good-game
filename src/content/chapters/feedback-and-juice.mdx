同一个「点击命中」的动作，加不加反馈，是两款游戏的区别。

前者只是数字变了；后者是数字炸开、屏幕一震、声音一响、手柄一抖。玩家说不出哪里不同，但会觉得「这个游戏打起来很爽」。

这一章把「爽」拆成可以逐项实现的清单。

## 反馈的三大类

<CompareTable caption="反馈手段清单：视觉、听觉、触觉">

| 类别 | 手段                       | 作用                   | 实现成本 | 常见误用                     |
| ---- | -------------------------- | ---------------------- | -------- | ---------------------------- |
| 视觉 | 飘字（伤害/收益数字）      | 让结果可被读到         | 低       | 数字太多、太快，变成噪音     |
| 视觉 | 缩放弹跳（punch）          | 让动作有「打击」的重量 | 低       | 幅度过大，界面抖动失控       |
| 视觉 | 闪白 / 变色                | 强调命中瞬间           | 低       | 白闪太强，长时间玩刺眼       |
| 视觉 | 粒子迸发                   | 提供方向与材质信息     | 中       | 粒子数量不设上限，低端机掉帧 |
| 视觉 | 屏幕震动                   | 传递冲击力             | 低       | 无差别震动，久了令人不适     |
| 视觉 | 顿帧（hit stop）           | 制造「砍到了」的实感   | 低       | 顿帧过长，操作变黏           |
| 视觉 | 拖影 / 残像                | 强调速度               | 中       | 与低帧率叠加后更糊           |
| 视觉 | 后坐力 / 位移回弹          | 让攻击有反作用力       | 中       | 位移过大，影响判定可读性     |
| 听觉 | 音效分层（起手/命中/收尾） | 让动作有完整弧线       | 中       | 只做一个音，动作听起来是断的 |
| 听觉 | 音高随机化                 | 避免机械重复           | 低       | 随机范围过大，听起来跑调     |
| 听觉 | 混音优先级                 | 重要声音不被淹没       | 中       | 全部同音量，关键提示听不见   |
| 触觉 | 短震动（手机）             | 补上「手上」的感觉     | 低       | 每个操作都震，很快被关闭     |
| 触觉 | 差异化震动（强度/节奏）    | 区分不同事件           | 中       | 强度差异太小，感知不到       |

</CompareTable>

## 亲手对比一次

下面这个实验台把上面这些手段做成了开关。先点「全关」打几下，再点「全开」打几下——差距不需要文字解释。

<JuiceLab />

建议按这个顺序试：

1. **只开飘字**：能读到数字了，但动作仍然是「软」的。
2. **加上缩放弹跳与顿帧**：同样的动作突然有了重量。
3. **再加上音效与震动**：反馈开始「多通道」，这是绝大多数商业产品的最低配置。
4. **再加上粒子与闪白**：接近「很爽」，但也开始接近「过量」。

## 过犹不及：反馈需要留白

反馈最容易犯的错不是「不够」，而是「太多」。

原因是感知有上限。当每一个动作都伴随飘字、震动、粒子、音效时，玩家的大脑会把这些刺激**平均化**——所有反馈都变成背景噪音，重要的那一个反而不突出。

所以真正专业做法是**分级**：

<CompareTable caption="反馈分级：让强度与事件重要性对应">

| 事件等级 | 例子                 | 反馈配置                        |
| -------- | -------------------- | ------------------------------- |
| 普通     | 普攻命中             | 轻飘字 + 轻微缩放 + 单层音效    |
| 强化     | 暴击、连击达成       | 飘字放大 + 顿帧 + 粒子 + 高频音 |
| 关键     | 击杀、破防、通关     | 全通道 + 屏幕震动 + 慢动作      |
| 稀有     | 抽到稀有物、达成成就 | 专属演出 + 专属音效 + 长震动    |

</CompareTable>

分级的另一面是**留白**：普通攻击越克制，关键一击才越有份量。一个所有攻击都全通道拉满的游戏，玩十分钟就会让人疲劳。

<Callout type="warning" title="两个具体的坑">
**其一：反馈与判定不一致**。画面炸得很响，但伤害数字很小或没打中——玩家会觉得「看起来很厉害，实际上没用」。反馈的强度必须与真实的游戏结果对应。

**其二：无障碍与体感**。屏幕震动、强闪白、高频音效对部分玩家是不适甚至有害的。系统设置里应当允许关闭震动与闪烁，并且默认遵守系统的「减少动态效果」偏好。

</Callout>

## 反馈与手感的区别

两章内容常被混在一起，这里划清边界：

- **手感**（第 12 章）是**输入到动作**之间的那一段：你按下去，角色多久、以什么曲线响应。
- **反馈感**（本章）是**动作到结果**之间的那一段：你的动作发生了什么，世界怎么告诉你。

手感差，玩家会觉得「不听使唤」；反馈差，玩家会觉得「打了没感觉」。两者可以由完全不同的团队负责，但必须一起调——因为玩家感知到的是一个整体。

## 这一章可以带走什么

- 反馈分三类：视觉（飘字、缩放、闪白、粒子、震动、顿帧、拖影、后坐力）、听觉（分层、音高随机、混音优先级）、触觉（震动强度与节奏）。
- 每一项都有常见误用；最重要的不是加，而是分级。
- 反馈要按事件重要性分级，普通克制、关键拉满；留白决定份量的感知。
- 反馈强度必须与真实结果一致，否则玩家会觉得「看着厉害其实没用」。
- 震动与闪烁应可关闭，并尊重系统的「减少动态效果」设置。
